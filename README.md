# InventoryIQ - RevolutionUC 

InventoryIQ is a smart inventory tracking and analytics system designed to help businesses monitor product usage, identify trends, and make datadriven decisions in real time.

Built during a 24-hour hackathon, this project combines a modern web frontend with a Python backend to visualize inventory data and highlight trending products.

---

## 🧠 Features

- 📊 **Real-Time Inventory Tracking**
  - Monitor product usage and stock levels

- 📈 **Trending Products Dashboard**
  - Visual bar graphs showing most popular items
  - Helps identify “hot” products based on recent orders

- 🔮 **Predictive Insights (WIP)**
  - Forecast ingredient usage
  - Assist with restocking decisions

- 🌐 **Full Stack Application**
  - Frontend: React (Vite)
  - Backend: Flask (Python)
